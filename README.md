## 🚀 如何运行

这些代码大多是基于标准输入输出 (`cin`/`cout` 或 `scanf`/`printf`) 的控制台程序。

**环境要求：**
- C++ 编译器 (g++, clang++, 或 MSVC)
- 建议支持 C++11 或更高标准

**编译运行示例：**
```bash
# 使用 g++ 编译 (以 字符统计 为例)
g++ 字符统计.cpp -o char_count -std=c++11

# 运行
./char_count
